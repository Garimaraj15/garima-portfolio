## ⚙️ Run This Project Locally

Want to explore the code or run my portfolio on your machine?

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Garimaraj15/garima-portfolio.git
```

**2. Navigate to the project**

```bash
cd garima-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:3000
```

**6. Build for production**

```bash
npm run build
```

*Note: Configure any required environment variables locally before running API-dependent features. Never commit API keys or secrets.*
